# HTB-challenge-write-ups
A curated collection of HTB challenge write-ups documenting my hands-on cybersecurity journey
this challenge was all about practicing the basics of reverse engineering by looking inside a binary, spotting hard-coded strings like a password and a flag, and realizing how unsafe it is to store sensitive info directly in code.
I practiced using Linux command line tools, reading binaries with string-like utilities. 
The big takeaway? Don't hardcode secrets in applications because they can be easily discovered.(https://labs.hackthebox.com/achievement/challenge/3927525/806)
